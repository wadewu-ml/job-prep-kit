# lessons/ · 方法课索引

按当前问题选读，不用依次学完。自己的经验先记在考后复盘里，有反复可用的方法时再整理成笔记，无须遵循编号或固定格式。

## 通用方法课（10 节）

| 编号 | 主题 | 解决什么问题 |
|---|---|---|
| 0001 | 薪资闸门与信息源分级 | 区分未知与冲突，核对固定与浮动薪酬 |
| 0002 | 宣讲会价值筛选 | 哪些宣讲值得跑（只认现场可行动环节） |
| 0003 | 技术叙事锚点 | 讲课题先给"是什么"，60 秒四句式开场 |
| 0004 | 内推两种提交模式 | A 给码自投 / B 员工代投；具体规则逐公司确认 |
| 0005 | 适配性问题答法 | 性格/缺点/倒班出差题：翻译成岗位匹配证据 |
| 0006 | 临场回答结构 | 压力下的开口动作 + 定性/证据/回岗三段骨架 |
| 0007 | 学校到公司思维转换 | 从"学过什么"切换到"能交付什么" |
| 0008 | 反问环节策略 | 2–3 个名额怎么分；底线题怎么问出口 |
| 0009 | 对着 JD 讲匹配 | "你为什么适合"的标准答法与备面动作 |
| 0010 | 面试量与松弛度 | 松弛 = 选项数量 × 反馈闭环；练手/命中分开 |

## 课程之间的关系

- 投递筛选：0001（薪资）→ 0002（宣讲）→ 0004（内推）
- 面试表达：0003（讲清课题）→ 0009（讲清匹配）→ 0006（临场结构）→ 0005（适配题）→ 0008（反问）
- 认知与节奏：0007（思维转换）贯穿表达层；0010（练手节奏）贯穿全程
