# 0007 · 从学校到公司：评价体系的切换

> 定位：认知课。解释"为什么我在学校表现很好，面试却总觉得错位"。
> 适用：理解面试官到底在考什么，从而调整所有回答的取向。

## 一、两套评价体系

| 维度 | 学校（学生熟悉的） | 公司（面试考的） |
|---|---|---|
| 评价对象 | 你**学过什么**（课程、分数、学历） | 你**能用来做什么**（任务、产出、协作） |
| 证据形式 | 成绩单、学分、排名 | 做成过的事、可迁移的动作、结果 |
| 时间观 | 学会了就算拥有 | 上手要多久、能不能独立交付 |
| 风险偏好 | 答错扣分，不会可以不说 | 出问题要能定位、敢担责、能协同 |
| 个人定位 | 个人努力、个人成绩 | 你是流程里的一环，接口和协作很重要 |

**核心转换**：面试官的每道题都在问一个底层问题——**"把你放进这个岗位，你能不能转起来、多久能转起来、会不会给团队添乱。"**

## 二、由此推出的回答取向

1. **课程和成绩能证明基础，项目能补充应用证据**。"我学过 X"是学生语言；要接一句转换："其中【某原理/方法】正是我现在做【某件事】时用的语言/工具。"
2. **优先说明实际做过的事，课程项目也可以**：项目、论文、平台经历、实习、带人——按"背景一句话 → 我的动作 → 结果"讲（见 `0003`、`0009`）。
3. **主动证明"上手快"**：提你**独立**操作设备/方法的时间点、从学到独立用了多久、给别人出过结果/带过新人。
4. **谈问题与失败时，给排查路径而不是辩解**：公司怕的不是出错，是出错后找不到人、说不清原因。讲一次"现象 → 我怎么定位 → 怎么解决 → 后来怎么避免"。
5. **协作题答"接口"**：你跟谁对接、交付什么、冲突怎么处理——别只说"我团队合作能力强"。

## 三、学生思维的五个典型信号（需要结合具体面试理解）

| 信号 | 面试官的潜台词 | 改法 |
|---|---|---|
| "我学过这门课" | 所以呢？能干活吗 | 接一个用它解决问题的实例 |
| "我虽然没做过，但我可以学" | 每个人都这么说 | 给证据：以前多快学会过类似的东西 |
| 只讲导师/团队，找不到"我" | 你自己到底做了什么 | 明确"我负责的是……"，用第一人称讲动作 |
| 问职业规划答"想多学东西" | 学完要走？ | 落到岗位：前半年上手哪些活、第二年独立担什么 |
| 对加班/倒班/地点完全没概念 | 没认真考虑过这份工作 | 提前查、反问时问清（见 `0008`），按真实底线回答 |

## 四、一张对照表：把学生资产翻译成公司语言

| 你的资产 | 别这么说 | 这么说 |
|---|---|---|
| 课程 | "我学过 X" | "X 里的【原理】是我做【某分析】时的工具，比如……" |
| 论文 | 罗列影响因子 | "我独立负责【环节】，解决了【问题】，结论是【】" |
| 工具使用 | "我会用 X" | "我用 X 完成了【任务】，处理过【具体问题】，交付了【成果】" |
| 带师弟师妹 | "我乐于助人" | "我带新人从安全培训到独立上机，沉淀了一份操作清单" |
| 实习 | "我在某公司实习过" | "我在【工序/项目】上每天处理【任务】，发现并改进了【】" |

> 表格里的事实必须真实，从 `../records/facts.md`取；没有的经历不要编。

## 五、一句话

> **学校考"你拥有什么知识"，公司考"你能交付什么结果"。把每一句"我学过"翻译成"我用它做成过什么"。**
