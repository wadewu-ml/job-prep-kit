# 0005 · 适配性问题：把"性格"翻译成"岗位匹配证据"

> 定位：回答"你觉得自己适合这个岗位吗 / 你的缺点是什么 / 你性格内向吗 / 能不能接受出差倒班"这类题。
> 适用：HR 面、主管面的适配性/压力题。

## 一、底层原则：没有好坏性格，只有人岗匹配

- 同一个特质在 A 岗是减分、在 B 岗可能是官方明文要求。
  - 例如，独立完成任务与协调多人推进需要不同的行为证据，不能只凭内向或外向判断。
- 所以回答这类题**不是表演一个"正确人格"**，而是：
  1. 先判断这个岗到底奖励什么行为（读 JD 职责，不读岗位名）；
  2. 用你**真实的行为证据**证明你具备该行为；
  3. 不匹配的部分，给出"我怎么处理"而不是否认。

## 二、四类高频题的答法

### 1. "你觉得你适合这个岗位吗 / 为什么选你"

→ 这是匹配题，不是性格题。**对着 JD 逐条说**，方法见 `0009`。

### 2. "你的缺点是什么 / 你最大的不足"

- 公式：**真实但不致命的缺点 + 你已经采取的具体动作 + 可观察的改善**。
- ❌ 假缺点："我太追求完美"（面试官听腻了，且不真诚）
- ❌ 致命真缺点："我不喜欢跟人打交道"（投客户岗时等于自我排除）
- ✅ 例："我第一次讲复杂技术问题容易陷进细节，对方抓不到重点。后来我固定先讲一句结论再展开，组会汇报时会先写三句话提纲。"
- 选的缺点要**与岗位核心要求不冲突**；与核心要求冲突的缺点，要么别投这个岗，要么准备可信的补偿证据。

### 3. "你性格内向/外向吗"

- 不接受非黑即白的框。**用工作场景里的行为回答**：
  > "我在【实际场景】中会【具体行为】。遇到【需要合作的任务】时，我采用【真实做法】推进。这与岗位中的【明确职责】有关。"
- 关键：**把性格词替换成具体行为**，再把行为接到 JD 上。

### 4. "能接受加班 / 倒班 / 出差 / 驻场吗"

- 这是双向信息题，不是表忠心题。
- **你的底线在 `PROFILE.md` 的求职偏好，按底线真实回答**——现在勉强答应，入职发现要倒班，代价远大于面试时说实话。
- 想了解真实强度又怕显得计较，用 JD 措辞反问（见 `0008` 路径 A）：
  > "JD 里两次提到抗压能力，我想了解一下日常的加班强度和值班/倒班是怎么安排的？"
- 能接受的部分说清边界："短期出差和项目期加班没问题；长期常驻客户现场我想了解一下频率再确认。"

## 三、一条反向纪律：面试也在帮你排除错岗

- 如果一个岗位反复要求你最不适应、且不打算改变的工作方式（如极度抗拒社交却要天天客户应酬），**面试时如实暴露不是失误，是低成本的互相筛选**。
- 一场不匹配的面试最大的价值，是产出一条硬判据："这类 JD 的日常是不是我要的"。把判据写进复盘（`interviews/` 中的复盘记录），下次看到同类 JD 直接筛掉。

## 四、一句话

> **适配题不评好坏，只评匹配。不表演人格——拿 JD 要的行为，配你真实做过的事；底线问题如实说，面试是双向筛选。**
