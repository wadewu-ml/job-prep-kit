# 求职助手工作流程

根据当前任务进入一个流程，不强迫使用者先填完所有材料。

| 当前问题 | 流程 | 验收结果 |
|---|---|---|
| 没有可用简历或想改稿 | [01 简历制作](01-简历制作.md) | 事实可查、可编辑母版、已检验的投递文件 |
| 不知道哪些岗位值得投 | [02 岗位筛选](02-岗位筛选.md) | JD匹配证据、未知条件、可执行建议 |
| 填表慢、忘记进展和截止 | [03 投递管理](03-投递管理.md) | 复用字段、官方回执、唯一台账和日程 |
| 笔试准备/面试模拟/考后复盘 | [04 笔面试准备](04-面试复盘.md) | 针对薄弱环节练习、模拟追问、下一场改动 |
| 有录用，如何选择与签约 | [05 Offer决策](05-Offer决策.md) | 同口径比较、待核条款、本人决定 |

每周检查：当前瓶颈是机会不足、简历表达、专业准备还是流程跟进？选一项改进，查下周官方节点。统计有明确分母的投递→测评→面试→offer，不把小样本波动归因为个人能力或某个单一改稿。
