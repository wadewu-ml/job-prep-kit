# 投递与日程

选一种维护方式即可：

- 工具方式：只改 `applications/data.json`，运行 `python scripts/tracker.py render --workspace <私人目录>`，生成总表、时间轴和近期日程。
- 手工方式：沿用自己的主表，或复制公开项目的 `applications/投递总表.md`。收到通知直接更新同一行，不另建重复台账。

完成的节点标为完成；考核已结束但未收到结果时仍是待反馈。原题、准备与复盘放 `interviews/`。

跨工作区更新时先核公司别名、招聘项目、志愿和来源时间，避免重复申请或把过期汇总覆盖新回执。生成器会保护手写文件；想迁移时先用 `--output-dir` 生成预览再核对。
