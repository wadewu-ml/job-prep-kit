# scans/ · 校招动态日报存档

每天一份 `校招日报-YYYY-MM-DD.md`，由每日扫描任务（或你自己）写入。

## 日报该写什么（固定结构）

1. **今日新增**：新开放的校招公告、新出现的对口岗位（只列候选，不改主台账）
2. **状态变化**：已关注企业的截止/延期/新场次
3. **待合并变化清单**：建议并入主台账/时间轴的条目，等本人确认后再合
4. **本校宣讲会**：引用 `../applications/宣讲会监控-latest.md` 的命中场次
5. **信息缺口**：今天没核到、需要继续查的

## 纪律

- 日报只写本文件，**不直接改** `applications/data.json` 或手工主表。
- 历史日报不回溯修改——它是当时的记录；纠错写在新一天的日报里。
- 每条事实标来源层级（①官方 ②本校就业网 ③外校就业网 ④第三方）与核验日期。
- 已放弃企业（主台账"已放弃"名单）不再出现在推荐里。
- 纯宣讲会（现场无收简历/扫码投递/笔试测评/初面/主管答疑）默认不推荐、不进主日程，判据见 `../lessons/0002-宣讲会价值筛选.md`。

## 手动跑一次

没有自动化时，按上面 5 个小节手写，15–20 分钟即可：打开本校就业网 + 目标企业招聘公众号/官网各扫一遍。
