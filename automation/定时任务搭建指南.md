# 可选扫描与定时运行

个人工作区由 scripts/init_workspace.py 创建。automation/config.json 默认是未配置骨架，需要确认学校官方就业网后填写。关键词、白名单与排除词仅维护在该 JSON 中，PROFILE 只作指引。

先按 [适配说明](适配其他学校.md) 填好私人配置，再运行以下命令。config.example.json 只是合成示例，不能直接访问真实站点：

```powershell
python -B automation/career_watch.py private/automation/config.json --check
python -B automation/career_watch.py private/automation/config.json
```

使用已有配置时保留个人设置，只调整当前网站需要的字段。脚本只抓公开静态列表，不能判断 JD 匹配、实际待遇或现场价值；输出候选由助手按证据规范复核。

返回码：0=读取范围正常结束；1=配置/输出失败；2=部分失败、解析异常、重复页或触及页数上限。返回2时仍可保留已抓条目，但不能认定窗口完整。--check 不写文件。完整抓取也只意味着已配置页面范围，不代表全校、全网无遗漏。

报告写 private/applications/宣讲会监控-latest.md，快照写 private/automation/captures/。新增/变化仅比较抓取条目；窗口滚动消失不等于截止，不自动修改台账。首次运行都算首次发现。

## 有需要才创建定时任务

使用者可以在系统任务计划或支持调度的助手中设置每天一次运行以上命令，使用实际 Python 和项目绝对路径。安装本项目不会创建任务；用户明确要求后，助手应使用当前环境支持的调度工具，验证实际保存和试跑结果。

扫描任务提示词：

> 运行已配置的 career_watch.py，记录退出码和覆盖范围。读取个人台账，过滤已放弃对象；按官方原文核实有无可行动事项。只更新扫描产物，不替用户申请或改变志愿。无变化保持安静；有重要新机会、真实截止变更、抓取失败或需要本人行动才通知。来源优先企业官网和学校官方就业网。

企业招聘日报需要助手或人工研究，脚本没有实现通用企业官网、公众号或邮箱采集。提示词：

> 按 reference/evidence-rules.md 检查已关注岗位的官网和学校就业网，列新增、变化、待合并事实及未能核实范围。所有日期附原文和核验时间，第三方只作线索。状态合并由助手核实后按已有授权完成，申请决定仍归用户；无实质变化不重复推送。
