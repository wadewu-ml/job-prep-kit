# 适配学校官方就业信息网

脚本支持公开静态 HTML 列表，依赖 Python 3.10+ 标准库。网站用动态API、登录或访问挑战时，需要另行适配或人工检查，不能仅改域名就保证成功。

1. 从学校官网确认就业网链接，找到列表页，读取真实页面结构。不要猜域名、租户或届次。
2. 在私人 automation/config.json 填 base_url、school、keywords、whitelist、exclude、list_pages；参考合成示例的字段结构，但域名、页面路径和解析规则必须来自目标站点。个人偏好只在配置维护一份。
3. 每个列表配置 name/key/path/page_path、block_pattern（单条HTML块）、link_pattern（完整链接匹配，第一捕获组为id）、date_mode（event举办日期/publish发布日期）、extra_patterns。标题提取优先 title 属性；日期为条目中首个 YYYY-MM-DD 或 YYYY/MM/DD，若含多个日期需修改解析器，不能猜其含义。
4. empty_pattern 可配置**已确认的空列表提示**，用于正常结束；未配置且没有识别到条目会报告可能改版/受限。不能用任意空HTML作为成功标志。
5. days 是公告向前天数（含今天）；future_days 是活动向后天数，活动同时保留昨天。max_pages 是读取上限，不意味着窗口完整，触及上限会返回2。不会因遇到旧置顶提前停页。
6. request_interval 默认1秒；请保留温和频率。max_items 可限制展示量。只按标题关键词匹配，不会读取JD或识别所有对口公司，名称不命中可能漏选。
7. 运行 --check，抽查首尾条目的标题、链接、日期和现场地址与原网页一致。count=0 不足以证明无招聘，应同时看 error 和覆盖范围。未完整核验不要宣称开箱即用。

输出仅代表已配置列表。网站动态更新、匹配词不全、读取上限都影响召回；企业官方招聘应通过工作流另行核查。
