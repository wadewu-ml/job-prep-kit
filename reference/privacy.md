# 私人资料与公开模板

公开仓库只保留空白模板、通用流程、学校公开抓取配置和合成测试数据。私人资料默认写入 private/；这个目录被整个忽略，内部也有忽略所有文件的 .gitignore。忽略规则不是加密，不阻止强制添加、手工上传或其他备份服务同步。

## 使用时

- 先初始化，再填资料。根目录 PROFILE.md 等是已跟踪模板，直接编辑后提交会泄露内容；给已跟踪文件加 ignore 也不能撤回历史。
- 简历仅放必要职业信息；身份、家庭、健康、联系人、成绩明细留在私人网申资料中，按表单要求提供，不自动放公开简历。
- 不把账号密码、cookie、令牌放进配置或通知台账；申请凭证只截取成功状态、岗位和必要编号，遮掉无关身份信息。
- 简历可编辑源文件、PDF、历史稿和面试记录均是私人资料。查看旧记录不会自动授权向其他项目同步。

## 分享前

1. 使用干净的公开模板；不要从填好的私人工作区“删姓名后”直接发布。
2. 检查 Git 暂存区和历史、附件、元数据、批注、修订、隐藏文字、头像、二维码和截图。
3. 研究题目、导师、论文 DOI、独特指标、公司与精确日期组合也可能定位个人，改用完全合成的示例。
4. 新学校配置仅保留公开 URL 和解析规则，删除个人关键词、白名单、账号和通知内容。

若已经公开了隐私，仅删除当前文件并不清除 Git 历史；暂停传播，按实际泄露范围处理历史与访问凭据。任何自动扫描只能辅助检查，不能宣称绝对无隐私。
